# 最高タワー工房（試作版）

中学1年の技術の授業（50分×1コマ）で使う、地震に強い建物づくりのゲーム型教材です。
柱・梁・筋交いを組み、材料を選んで、地震で揺らして「なぜ倒れたか／倒れなかったか」を確かめます。

授業で使う第1章「四角と三角」・第2章「材料を選ぶ」と最高タワーチャレンジのほか、早く終わった生徒や発展学習向けに、第3章「重さと重心」・第4章「揺れ方と共振」・第5章「風」・第6章「制震と免震」と、自由に作る実験モードがあります。

## 遊び方

1. ステージを選び、依頼（目標の高さ・予算・地震の強さ）を読む
2. 材料（木材・鉄骨・鉄筋コンクリート）を選ぶ
3. 方眼の点から点へドラッグして部材を置く（地面の線につながった所が基礎になる）。置いた部材はタップすると選べて、材料を変えたり消したりできる
4. 「地震スタート！」を押し、いちばん先にこわれそうな部材をタップして予想する（「どこもこわれないと思う」も選べる）
5. 地震で試験する（予算オーバーでは試験できない）。部材の内側の色と、つなぎ目の丸の色で、こわれそうな所を見る（青＝余裕、赤＝こわれそう、×＝こわれた）
6. 結果カードで、予想の答え合わせ（大当たり・おしい・はずれ）を見る。「スロー再生で見る」で、最初にこわれた瞬間（黄色の輪）を巻き戻して確かめられる
7. 星3つ（倒れない・こわれた所0・揺れ幅が高さの2%以下）を目指して改良する。クリアすると「なぜ？」の解説が、ひとことまとめ付きで出る
8. 授業の最後に、最高タワーチャレンジの右上の「ふりかえり」（または結果カードの「ふりかえりを書く」）でふりかえりシートを開く。名前と4つの問いに答えて「画像で保存する」と、名前・答え・ビルの画面が1枚の画像（PNG）になるので、それを Classroom などで提出する。ふりかえりはチャレンジのときだけ開ける

## クラスランキング（先生用）

生徒の記録を、先生の Google フォームに集めます。サーバーは使わず、記録はフォームの回答（スプレッドシート）にだけ残ります。

**準備（授業の前に1回、10分ほど）**

アプリの「ステージ一覧」→「先生用：クラスランキングの準備」を開き、画面の①〜⑤を上から順にやる。

1. **フォームを作る**：「スクリプトをコピー」→「Apps Script を開く」。中の文字を全部消して貼りつけ、「実行」を押す（初回は自分のアカウントで許可する。「確認されていません」と出たら「詳細」→「移動」）。中身は [`src/teacher/rankingForm.gs`](src/teacher/rankingForm.gs)。先生のドライブに、フォーム「最高タワー工房 クラスランキング」と回答のスプレッドシートができる
2. **ウェブアプリとして公開する**：Apps Script の右上「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」。アクセスできるユーザーを「全員」にしてデプロイし、出てきた「ウェブアプリの URL」をコピーする
3. **URL をアプリに貼る**：アプリがウェブアプリにつないで確かめ、生徒に配るクラスリンクを作る（ウェブアプリが記録を送るフォームのリンクも返すので、貼るのはこの URL だけでよい）
4. **クラスリンクを配る**：Classroom などで配る。生徒は結果カードの「クラスに送る」でニックネームを入れると、記入済みのフォームが開く。「送信」を押せば完了
5. **ランキングを映す**：「ランキングを大きく映す」で、教室の画面用に大きな文字で出る（30秒ごとに自動で更新）。生徒はチャレンジの右上や結果カード、ステージ一覧の「ランキング」で見られる

- ランキングは、最高タワーチャレンジの記録を、ニックネーム（と組・班）ごとに「星3つのままの最高の高さ」で高い順に並べる（同じ高さなら費用の安い人が上。クリアしなかった試験は 0 m、先生のテスト送信は入らない）。スプレッドシートの「ランキング」シートにも星3つの記録だけが高い順に出る
- アプリの中のランキングでは、星1・2でもっと高く建てた記録を「参考」として出し、自分のすぐ上の人まで「あと何 m」かを出す
- ver.0.26 以前のスクリプトのままでも動く（そのときは高さだけで並ぶ）。新しい並べ方にするには、スクリプトを貼り直してウェブアプリを新しいバージョンでデプロイし直す
- 公開されるのは、チャレンジの記録の「順位・組班・ニックネーム・高さ・星」の上位50人と、記録を送るフォームのリンクだけ（時刻・費用・メールなどは出さない）。URL を知っていればだれでも見られるので、本名は使わない
- 学校の設定で「全員」が選べないときは、②③をとばし、①の実行ログ（または「先生用メモ」シート）のクラスリンクを配る。ランキングはスプレッドシートの「ランキング」シートを画面に映す
- 授業が終わったら「デプロイを管理」からアーカイブすると、ランキングは見られなくなる
- 前の版のスクリプトを使っている場合は、新しいスクリプトに貼りかえて「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイし直す（URL は変わらない）

**自分でフォームを作るとき**

1. Google フォームに記述式（短文・入力チェックなし）の質問を作る。必須は「ニックネーム」「ステージ」「高さ」、任意で「組・班」「星」「費用」「結果」
2. フォームの「事前入力したURLを取得」で、各質問に `NAME` `STAGE` `HEIGHT` `GROUP` `STARS` `COST` `RESULT` を入れてリンクを取得する
3. アプリの「先生用：クラスランキングの準備」の③の欄にそのリンクを貼ると、生徒に配るクラスリンクができる
4. 回答のスプレッドシートを「高さ」で降順に並べ替えるとランキングになる（クリアしなかった試験は高さ 0 m で送られる）

## 開発

```bash
npm install
npm run dev     # 開発用サーバー
npm test        # 物理と教材としての正しさのテスト
npm run build   # dist/ に公開用ファイルを作る
```

- `src/physics/` … 物理計算（画面とは独立）
  - `materials.ts` 材料の性質（ゲーム用の値）
  - `design.ts` 生徒が作る設計図と見本
  - `quake.ts` 地面の揺れ
  - `world.ts` 質点とばねによる揺れの計算
  - `world.test.ts` 「四角は倒れ、三角は耐える」などの学びを守るテスト
- `src/game/` … ゲームのルール
  - `stages.ts` ステージ（依頼）の定義
  - `evaluate.ts` 試験の結果の評価（星）
  - `progress.ts` 進み具合・設計図・試験の記録・ふりかえりの保存（端末内）
  - `reflectionCard.ts` ふりかえりを1枚の画像（PNG）にまとめる
  - `predict.ts` 予想の答え合わせと、部材の呼び方（「2階の筋交い」など）
  - `replay.ts` 試験のコマ送り記録（スロー再生用）
  - `classForm.ts` クラスランキング用の Google フォームのリンク作り
  - `classRanking.ts` アプリ内のクラスランキング（先生のウェブアプリから読む）
  - `stages.test.ts` 各ステージが「工夫すれば解ける／工夫しないと解けない」ことのテスト
- `src/teacher/rankingForm.gs` … 先生が Google Apps Script で動かす、ランキング用フォームとランキング表を作るスクリプト
- `src/render.ts` … 描画
- `src/main.ts` … 画面の操作

### 物理のしくみ

- 節点（つなぎ目）は重さを持つ点。床や人の重さとして、地面以外の節点に一定の重さを足している
- 部材は伸び縮みに逆らうばね。伸び縮みが材料の限界を超えると折れる
- 接合部は部材どうしの角度を保つ回転ばね。曲がりすぎると壊れてピン（自由に回る）になる
- 地面の揺れは、いくつかの周期の正弦波を重ねたもの

四角い枠は接合部の曲げだけで横の力に耐えるため、揺れが大きくなり接合部が壊れて倒れます。
筋交いがあると部材の伸び縮みで耐えるため、揺れが小さく済みます。

数値は実物の大小関係に合わせたゲーム用の値で、実際の建物の強さを表すものではありません。
